# Grimbart Schmiede

Сайт кузні-крамниці з українською, англійською та німецькою мовами, каталогом, кошиком і формою замовлення. Дані товарів і купонів зберігаються у `data/products.json`, переклади інтерфейсу — у `data/translations.json`.

## Запуск

Каталог завантажується через `fetch`, тому сайт потрібно відкривати через локальний вебсервер, а не напряму як `file://`. Наприклад, у корені проєкту:

```bash
python -m http.server 8000
```

Потім відкрийте `http://localhost:8000`.

## Каталог товарів

Товари зберігаються у `data/products.json`. Файл містить валюту каталогу та масив виробів:

```json
{
  "currency": {
    "name": "срібний денарій",
    "plural": "срібних денаріїв",
    "symbol": "д."
  },
  "products": [
    {
      "id": "wall-candlestick",
      "name": "Настінний свічник «Ворон»",
      "category": "Для дому",
      "price": 180,
      "description": "Кований свічник ручної роботи.",
      "popular": 98
    }
  ]
}
```

Ціна вказується цілим числом у срібних денаріях. Об'єкт `currency` задає назву, форму множини та скорочення валюти, які використовуються інтерфейсом. Головна показує популярні вироби, а каталог читає той самий JSON і дозволяє сортувати та фільтрувати товари. Натискання на назву виробу відкриває `product.html?id=<id>` з повним описом.

`script.js` отримує `data/products.json` через `fetch`, перевіряє структуру й заповнює сторінки даними. Тому відкривайте сайт через локальний вебсервер, а не напряму як `file://`.

## Кошик і товари

Картка товару та сторінка виробу показують зображення з `image` у JSON. На сторінці виробу можна вибрати варіант, кількість і додаткову гарантію. Кошик зберігається у браузері, тож не зникає після переходу між сторінками.

Доступні купони задаються в секції `coupons` файлу `data/products.json`. Зараз для прикладу налаштований код `IRON10` зі знижкою 10%. Щоб додати купон, оновіть також перевірку дозволених кодів у `google-apps-script/Code.gs`.

## Надсилання замовлень у Google Таблицю

1. Відкрийте надану таблицю й перейдіть до **Розширення → Apps Script**.
2. Скопіюйте код із `google-apps-script/Code.gs` у редактор Apps Script і збережіть проєкт.
3. Натисніть **Розгорнути → Нове розгортання → Вебзастосунок**. Виконувати як — **я**, доступ — **усі**. Підтвердьте дозвіл на доступ до таблиці.
4. Скопіюйте URL вебзастосунку, що закінчується на `/exec`, у `window.GRIMBART_ORDER_ENDPOINT` у `static/config.js`.
5. Розмістіть сайт на HTTPS-хостингу та зробіть тестове замовлення. Нові записи додаватимуться на перший аркуш таблиці.

Для простого надсилання вебзастосунок приймає запити відвідувачів, тому не публікуйте в ньому секрети чи ключі доступу. Код додає рядок із заголовками автоматично й записує контактні дані покупця та склад замовлення.
