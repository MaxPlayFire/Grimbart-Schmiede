# Grimbart Schmiede

Базовий сайт кузні-крамниці: головна сторінка, каталог із категоріями, сортуванням і фільтром ціни, а також окрема сторінка опису виробу. Інтерфейс використовує компоненти Bootstrap 5 для адаптивної навігації.

## Запуск

Каталог завантажується через `fetch`, тому сайт потрібно відкривати через локальний вебсервер, а не напряму як `file://`. Наприклад, у корені проєкту:

```bash
python -m http.server 8000
```

Потім відкрийте `http://localhost:8000`.

## Каталог товарів

Товари зберігаються у `data/products.json`. Файл містить валюту каталогу та масив виробів:

```json
{
  "currency": {
    "name": "срібний денарій",
    "plural": "срібних денаріїв",
    "symbol": "д."
  },
  "products": [
    {
      "id": "wall-candlestick",
      "name": "Настінний свічник «Ворон»",
      "category": "Для дому",
      "price": 180,
      "description": "Кований свічник ручної роботи.",
      "popular": 98
    }
  ]
}
```

Ціна вказується цілим числом у срібних денаріях. Об'єкт `currency` задає назву, форму множини та скорочення валюти, які використовуються інтерфейсом. Головна показує популярні вироби, а каталог читає той самий JSON і дозволяє сортувати та фільтрувати товари. Натискання на назву виробу відкриває `product.html?id=<id>` з повним описом.

`script.js` отримує `data/products.json` через `fetch`, перевіряє структуру й заповнює сторінки даними. Тому відкривайте сайт через локальний вебсервер, а не напряму як `file://`.
